Pengantar Web Mining

1. Apa itu Web Mining?

Web Mining adalah proses menemukan dan mengekstrak informasi dari internet menggunakan berbagai teknik penambangan data.

2. Web Content Mining

Web Content Mining merupakan proses mengekstrak informasi berguna dari dokumen-dokumen web. Fokusnya pada konten halaman web seperti teks, gambar, audio, video, serta data terstruktur.

3. Web Usage Mining

Web Usage Mining merupakan proses ekstraksi informasi dari data yang dihasilkan melalui kunjungan halaman web dan transaksi.

4. Web Structure Mining

Web Structure Mining merupakan proses penemuan dan interpretasi pola dalam struktur tautan atau hyperlink di internet serta hubungan sosial antar pelaku yang berinteraksi di web.

5. Proses Web Mining

Proses Web Mining meliputi pengumpulan dan eksplorasi data, preprocessing dan transformasi, actual data mining, serta evaluasi model atau pola yang dihasilkan.
