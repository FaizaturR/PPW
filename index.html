Tentang Website

Website ini dibuat sebagai bagian dari tugas Web Mining. Data yang digunakan berupa berita dari website Detik.com dengan dua kategori, yaitu Sport dan Finance.

Proses crawling dilakukan menggunakan Python dengan library requests, BeautifulSoup, dan Trafilatura. Data yang berhasil dikumpulkan kemudian disimpan dalam dataset CSV.

Source code proses crawling dapat dilihat pada menu Crawling, sedangkan data hasil crawling dapat dilihat pada menu Hasil Crawling.
