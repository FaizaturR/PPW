Pengantar Web Mining

Pengenalan mengenai Web Mining

Apa Itu Web Mining?

Web Mining merupakan proses penerapan teknik data mining untuk menemukan dan mengekstraksi informasi atau pola yang bermanfaat dari sumber data yang terdapat di web.

Menurut Etzioni (1996), Web Mining merupakan penggunaan teknik data mining untuk secara otomatis menemukan dan mengekstrak informasi dari layanan web. Menurut Bing Liu (2007), Web Mining bertujuan menemukan pola-pola berguna atau pengetahuan dari struktur hyperlink web, isi halaman web, serta perilaku pengguna.

Tujuan Web Mining

Web Mining bertujuan membantu mahasiswa memahami dan menggunakan konsep dasar serta teknologi Web Mining, sekaligus dapat melakukan penelitian sistem informasi dalam konteks Web Mining.

Tantangan Pemrosesan Data Web

Web memiliki karakteristik data yang sangat besar dan kompleks, sehingga proses penambangan data pada web memiliki beberapa tantangan.

  • Web merupakan pangkalan data yang sangat besar.
  • Data tersedia dalam berbagai format seperti HTML, XML, dan text.
  • Web sangat kompleks.
  • Web sangat dinamis.
  • Web bukan domain yang spesifik.
  • Web mencakup berbagai jenis informasi.

Sumber: Turban et al. (2011), Decision Support and Business Intelligence Systems.

Taxonomy Web Mining

Web Mining terdiri dari beberapa bidang utama yang saling berkaitan, yaitu Web Content Mining, Web Usage Mining, dan Web Structure Mining.

📄

Web Content Mining

Proses mengekstrak informasi berguna dari dokumen-dokumen web. Fokusnya dapat berupa teks, gambar, audio, video, maupun data terstruktur seperti tabel dan daftar.

🕷️

Web Crawling

Proses pengumpulan dokumen atau data dari web secara otomatis. Crawling digunakan untuk memperoleh data web yang kemudian dapat dieksplorasi dan dianalisis.

🧹

Web Data Preprocessing

Proses mentransformasikan data ke dalam representasi yang sesuai dengan metode data mining, termasuk reduksi dimensi, seleksi fitur, dan transformasi teks menjadi vektor atau embedding.

🎯

Supervised Learning

Pembelajaran terawasi menggunakan data yang memiliki label untuk membangun model klasifikasi atau prediksi.

🔎

Unsupervised Learning

Pembelajaran tak terawasi digunakan untuk menemukan pola atau kelompok dalam data tanpa menggunakan label.

👥

Web Usage Mining

Ekstraksi informasi dari data yang dihasilkan melalui kunjungan halaman web dan transaksi, termasuk log dan data clickstream.

🔗

Web Structure Mining

Penemuan dan interpretasi pola pada struktur hyperlink serta hubungan antaraktor yang berinteraksi di web.

🚀

Deployment System

Tahap penerapan hasil atau model Web Mining ke dalam suatu sistem agar dapat digunakan dalam kebutuhan nyata.

Text Mining

Text Mining merupakan proses mendapatkan informasi yang berkualitas dari teks. Text Mining termasuk salah satu bagian dari Web Content Mining.

Beberapa tugas Text Mining antara lain:

  • Text categorization / classification.
  • Text clustering.
  • Concept/entity extraction dan topic modelling.
  • Sentiment analysis.
  • Document summarization.

Klasifikasi Dokumen

Klasifikasi dokumen bertujuan mengategorikan dokumen atau gambar yang sebelumnya belum pernah dilihat ke dalam kelas tertentu dengan seakurat mungkin.

Contoh aplikasi: kategorisasi berita, kategorisasi produk, dan deteksi spam.

Metode: Naive Bayes, Support Vector Machines (SVM), Deep Neural Networks, dan Transformers.

Pengelompokan Konten

Pengelompokan konten dilakukan dengan mencari kelompok dokumen berdasarkan ukuran kesamaan. Dokumen dalam satu kelompok lebih mirip satu sama lain, sedangkan dokumen dari kelompok berbeda memiliki kemiripan yang lebih rendah.

Aplikasi: pengelompokan hasil pencarian dan penemuan topik.

Teknik: K-Means, Hierarchical Clustering, S-BERT, serta ukuran kemiripan Cosine dan Jaccard.

Analisis Sentimen

Analisis sentimen merupakan tugas mengklasifikasikan polaritas teks pada tingkat dokumen, kalimat, atau fitur/atribut.

Nilai polaritas: Positif, Netral, dan Negatif.

Contoh penerapannya adalah analisis opini publik terhadap suatu isu dan analisis ulasan produk untuk mengetahui kepuasan pelanggan.

Web Usage Mining

Web Usage Mining berfokus pada ekstraksi informasi dari data yang dihasilkan melalui kunjungan halaman web dan transaksi.

  • Server access log.
  • Referer log.
  • Agent log.
  • Client-side cookie.
  • Metadata halaman, konten, dan penggunaan.
  • Clickstream atau catatan urutan klik pengguna.

Contoh aplikasi: Product Recommendation dan Personalized Search.

Web Structure Mining

Web Structure Mining berfokus pada penemuan dan interpretasi pola dalam struktur tautan (hyperlink) di internet serta hubungan sosial antaraktor.

Dalam Web Graph, halaman web direpresentasikan sebagai node dan hyperlink sebagai edge.

  • Menentukan otoritas halaman, seperti PageRank.
  • Mendeteksi komunitas online.
  • Menganalisis jaringan sosial digital.
  • Mengidentifikasi simpul penting melalui centrality.

Web Mining sebagai Gabungan Beberapa Bidang

Web Mining merupakan bidang yang menggabungkan beberapa disiplin ilmu, antara lain:

Natural Language Processing

Digunakan untuk pengolahan dan pemahaman data teks.

Machine Learning

Digunakan untuk menemukan pola dan membangun model dari data.

Database Systems

Mendukung penyimpanan dan pengelolaan data.

Social Network Analysis

Menganalisis hubungan dan interaksi dalam jaringan sosial.

Graph Mining

Menganalisis pola pada data yang direpresentasikan sebagai graph.

Proses Web Mining

1. Gathering and Exploration

Tahap pengumpulan dan eksplorasi data web yang meliputi crawling dokumen atau data, penggunaan Web API, memahami data, membuat ringkasan statistik, dan visualisasi data.

2. Preprocessing and Transformation

Tahap mentransformasikan data ke representasi yang sesuai dengan metode data mining. Prosesnya dapat meliputi reduksi dimensi, seleksi fitur, diskritisasi dan binarisasi, transformasi teks menjadi vektor atau embedding, serta integrasi berbagai sumber data.

3. Actual Data Mining

Data yang telah diproses digunakan sebagai input untuk menghasilkan model atau pola. Tahap ini meliputi penggunaan metode data mining, evaluasi model atau pola, dan iterasi.

  • Eksperimen dengan hyperparameter yang berbeda.
  • Mencoba beberapa metode lain.
  • Memperbaiki preprocessing dan pembangkitan fitur.
  • Meningkatkan jumlah dan kualitas data pelatihan.

Ruang Lingkup Project

Pada project ini, penerapan Web Mining dilakukan melalui proses Web Crawling untuk mengumpulkan data berita dari Detik.com pada kategori Sport dan Finance.

Data hasil crawling kemudian disimpan dalam dataset CSV dan digunakan pada tahap Web Data Preprocessing, TF-IDF, serta reduksi dimensi menggunakan PCA.
