Apa Itu Web Mining?

Web Mining merupakan proses penerapan teknik data mining untuk menemukan dan mengekstraksi informasi atau pola yang bermanfaat dari sumber data yang terdapat di web.

Web Mining memanfaatkan berbagai teknik untuk memperoleh informasi dari halaman web, struktur web, maupun aktivitas pengguna pada web.

🕷️

Web Crawling

Proses pengumpulan data atau halaman web dari internet secara otomatis menggunakan program atau crawler.

🧹

Web Data Preprocessing

Tahap persiapan data sebelum digunakan pada proses analisis atau pengolahan lebih lanjut.

📄

Web Content Mining

Proses menemukan informasi atau pola dari isi halaman web.

🔗

Web Structure Mining

Analisis struktur hubungan antar halaman atau dokumen yang terdapat pada web.

👥

Web Usage Mining

Analisis pola penggunaan web berdasarkan aktivitas atau perilaku pengguna.

🤖

Machine Learning

Teknik pembelajaran dari data yang dapat digunakan untuk menemukan pola dan melakukan klasifikasi maupun prediksi.

Ruang Lingkup Project

Pada project ini, fokus utama yang dilakukan adalah proses Web Crawling untuk mengumpulkan data berita dari Detik.com. Data dikumpulkan dari kategori Sport dan Finance.

Data hasil crawling kemudian disimpan dalam bentuk dataset CSV dan ditampilkan pada halaman Hasil Crawling.
